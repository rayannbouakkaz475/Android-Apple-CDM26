# Coupe du Monde 2026 - PWA iPhone + Android

Installation Android :
1. Ouvrir le lien GitHub Pages dans Chrome.
2. Appuyer sur ⋮.
3. Choisir Ajouter à l’écran d’accueil ou Installer l’application.

Installation iPhone :
1. Ouvrir le lien dans Safari.
2. Partager.
3. Sur l’écran d’accueil.

Ce pack contient manifest.json, service-worker.js et les icônes Android/iPhone.
